# Keep Foreground Subagent Streams UI-Only

Foreground **Subagent runs** stream live progress into the parent `Agent` tool row, with the invoked **Subagent type** visible in the call and stream headers; child thinking deltas are not shown, background runs keep the existing id/status/final polling behavior for now, and parent abort cancels the child rather than returning a partial transcript. The stream is UI-only and does not become parent LLM context: the final subagent result remains the only parent-context payload, while the collapsed tool row shows stable identity plus compact tool/progress markers instead of live assistant prose, and the expanded view can show a bounded transient event log. This trades perfect transcript fidelity, background parity, and post-abort partial recovery for context hygiene, readable in-progress UI, and a small first slice built on Pi's existing tool `onUpdate` and SDK `session.subscribe()` streaming seams.
