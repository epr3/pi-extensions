# Use Same-Turn Agent Calls for Subagent Fan-Out

To enable the parent Pi coding agent to delegate to multiple same-typed **Subagent runs**, keep the existing one-run `Agent` tool shape and rely on **Same-turn fan-out**: the parent emits multiple foreground `Agent` tool calls in one assistant turn, each with its own prompt and description, and each result remains an independent tool result for the parent to synthesize. This rejects an `Agent({ tasks: [...] })` batch parameter after comparing the amosblomqvist/pi-subagents design, because same-turn tool calls align with Pi's parallel tool execution model, preserve the simple existing API, avoid a new aggregate result contract, and keep failures scoped per **Subagent run**; the trade-off is that the extension should make foreground runs obey the same subagent concurrency cap and document the fan-out pattern clearly, while bounded nested delegation remains out of scope.
