# Revise the Inline-Only Presentation Restriction into an On-Demand Subagent Overview

`/subagents` — which previously answered with a textual notification listing — opens a read-only, dismissible (Esc/Enter), scrollable **Subagent overview** overlay in the TUI: one row per **Subagent run** naming run id, **Subagent type**, description, and textual state, active runs first then terminal and `outcome unavailable` rows, newest first within each group, current-session runs combined with reconstructed **Branch-local outcomes** and deduped by run id; where a TUI overlay is unavailable the textual notification stays. Hard to reverse once users habituate to `/subagents` as the inspection path, though the command remains usable everywhere. Surprising — earlier design documentation restricted run presentation to inline rows with "no separate dashboard", and dashboards usually drift toward becoming primary surfaces. Trade-off: an on-demand answer to "what is running right now (and what ran on this branch)" costs nothing while closed and adopts no live-update promise by itself, but the inline **Compact run rows**, **Launch receipts**, and **Attributed completions** stay the authoritative per-run record; the overview carries no activity tails, no result bodies, and no run controls, so it cannot become the place where runs are operated.
