# Use Hidden Agent Tool Params for Nesting Identity

Nesting policy identifies calling Subagent via hidden Agent tool param (`_parent_id`) injected into Subagent's system prompt, echoed by LLM on child spawn. `createAgentSession()` returns session whose active tool set restricted via `setActiveToolsByName()`: drops `Agent` for `plan`/`explore` and for `general-purpose` when `allowNestedSubagents` is false or `depth >= maxSubagentDepth`. Executor looks up parent in AgentManager, computes new run's `parentId` + `depth`. LLM = trusted courier for echoed parent ID. Hard to reverse once tests/clients assume hidden-param contract. Surprising — hidden tool params unusual; tool filter alone is user-visible effect. Trade-off: clean local enforcement vs wait for upstream Pi SDK to add `ctx.parentSubagentId`. Choose hidden params now to ship boundary without blocking on SDK; accept LLM as trusted courier.
