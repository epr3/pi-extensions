# packages/lsp/eval — committed model-choice reports

Reports generated by `scripts/lsp-tool-choice-eval.ts` (see
`scripts/lsp-tool-choice-eval.README.md` for the exact commands). Each report
records the guidance revisions compared, the model/provider/environment, the
task set with its intent, the observed tool choices per (task, variant), and
explicit unexecuted/unavailable-prerequisite notes. **Non-gating:** model
choice is variable, these reports describe what happened, and they never
operate as pass/fail; the extension's deterministic tests live under
`packages/lsp/__tests__/`.
